Initial release of effect-stripe - An Effect wrapper around the Stripe API

Features:
- Full Effect integration with type-safe error handling
- Support for core Stripe resources (Customers, PaymentIntents, Subscriptions, Prices, Products)
- Composable API using Effect's combinators
- Resource-safe client management with Effect Layers
- Comprehensive error types for Stripe API errors
